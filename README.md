# PDD — игра для изучения ПДД

Браузерная игра для подготовки к теоретическому экзамену РФ категории B: свободная поездка по городу, разбор нарушения, связанный вопрос и ссылка на ПДД.

## Документация

- [ТЗ и требования MVP](TZ-PDD-MVP.md) — поведение продукта, границы и критерии приёмки; часть решений пока предложена для согласования.
- [Веб-архитектура v1.0](ARCHITECTURE-WEB-v1.0.md) — полное описание архитектуры, игрового цикла и пограничных случаев.
- [Правила архитектуры и работы агента](AGENTS.md) — слои, зависимости, симуляция, учебные данные, история и проверки.

## Правила для AI-агента

Codex автоматически читает корневой `AGENTS.md` при запуске работы в этом репозитории. Открывай папку `pdd` как проект; для новой сессии не нужно вставлять правила в каждый запрос.

Ключевые правила находятся непосредственно в `AGENTS.md`. Там же задано чтение ТЗ перед реализацией. Автоматическое подключение в других AI-инструментах зависит от их поддержки `AGENTS.md`.

## Текущее состояние

Создан локальный Git-репозиторий с документацией. Основа из чата «архитектура»: **TypeScript + React + Phaser**, хранение истории в **IndexedDB**, карта и учебные материалы в локальных файлах. Первая версия работает без бэкенда.

Слои: `domain`, `use-cases` с портами, `adapters`, `presentation`, `bootstrap`. Дорожная логика живёт в домене, Phaser отображает мир, React показывает интерфейс. Основные правила и целевая структура закреплены в `AGENTS.md`; каталоги создаются по мере реализации.

Исходного кода, установленных зависимостей и команд запуска пока нет. При первой реализации нужно добавить сюда требования к окружению и фактические команды установки, запуска, тестов и сборки. Первый сквозной сценарий — STOP, разбор, сохранение и повтор.
