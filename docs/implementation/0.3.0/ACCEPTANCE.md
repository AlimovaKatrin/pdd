## Результаты технической проверки

Полный прогон перед коммитом #4: `npm run check` — 605 тестов, типы, ESLint, Stylelint, Prettier; `npm run build`; `npm run test:e2e` — 43 сценария (21 прежней карты, 22 нового города). После добавления проверки освобождения runtime повторно прошли все 606 тестов, типы, линтеры, форматирование и сборка.

После исправления освобождения Phaser полный прогон дал 21 успешный сценарий прежней карты и 22 успешных сценария нового города. Один тест клавиатуры начал нажимать пробел до переноса фокуса на дорогу. В него добавлено ожидание фокуса; отдельный прогон этого сценария прошёл 10 раз подряд. Таким образом, проверены все 44 сценария; полный запуск до исправления теста имел ненулевой код завершения.

Итоговый нагрузочный запуск прошёл за 600 секунд: 3213 м, 24 точки маршрута, максимум восемь машин, 1054 записи. Все выбранные бюджеты выполнены: p95 шага 1,2 мс, интервал кадров p95 16,7 мс, рост JS-памяти 3,06 МиБ, рост DOM-узлов 24, журнал до 211 мс. После удаления приложения ресурсы освобождены. Подробности и ограничения — в PERFORMANCE.md.

Сценарии покрывают старт, нарушение, разбор без вопроса, продолжение и исправленный повтор, завершение, старую историю и чтение после перезагрузки. Столкновение проверяется отдельно, включая отсутствие точного повтора и сохранение поездки при возврате.

## Оставшаяся работа

Нужны реальные поездки учеников, наблюдения о понимании приоритета и проверка самостоятельного исправления в другой ситуации. По их результатам нужно устранить мешающие проблемы и повторить затронутые проверки. До этого нельзя объявлять выполненным последний критерий ТЗ или закрывать #7/#8.

Удалённый CI и Vercel проверяются отдельно по SHA. Успешная локальная проверка не доказывает ни зелёный CI, ни публикацию основной версии.

На момент подготовки документа оба запуска GitHub Actions и Vercel прошли для `a27f6a9`. Следующий коммит `8139ee9` содержит исправление освобождения ресурсов и новые проверки; его локальные результаты приведены выше. Актуальные удалённые проверки следует смотреть в PR #20 по последнему SHA, не переносить прежний зелёный статус на новый коммит.
