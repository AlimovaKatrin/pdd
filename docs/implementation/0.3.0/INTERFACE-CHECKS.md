# Проверка интерфейса расширенного города

Задача #5. Проверено 18 октября 2026 года на Mac14,9: Apple M2 Pro, 32 ГБ, macOS 26.6.2. Основной браузер предпросмотра — Chrome с клавиатурой, рекомендуемое окно от 1024×650. Мобильное управление отсутствует.

| Окружение                                                           | Проверка                                                            | Результат |
| ------------------------------------------------------------------- | ------------------------------------------------------------------- | --------- |
| Playwright Chromium, 1440×900, 1280×720, 1024×650, 800×800, 700×700 | Старт, стабильность карты, инструкция, восемь новых причин, журнал  | Пройдено  |
| Установленный Chrome 155.0.8059.82, те же пять размеров             | Восемь новых причин, журнал из 1000 записей, прокрутка и фокус      | Пройдено  |
| Chromium, окно 1440×900, zoom 125%, 150%, 200%                      | Настоящее увеличение браузера, чтение полного разбора, Tab и Escape | Пройдено  |
| Chromium, 1024×650 и 700×700                                        | Встречная полоса, исправленный повтор, сохранённый разбор           | Пройдено  |
| Chromium, 1280×720 и 1024×650                                       | Столкновение, объяснение без назначения вины, возврат               | Пройдено  |

Камера и проезд проверяются клавишами в `city.spec.ts`. Машины обозначены М1, М2 и далее; эти же подписи присутствуют в разборе. Пешеход нового перехода обозначен П1. Приоритет не передаётся одним цветом. Скриншоты карты, разборов на компактных размерах и при увеличении просмотрены: текст и действия читаются, панель находится под картой, фокус выделен. При zoom 200% используется предусмотренная правилами дизайна прокрутка низкого окна.

В нижнюю панель добавлен безопасный возврат. Он доступен с клавиатуры и при обычном ожидании, сохраняет поездку и учитывает независимую паузу. Лимит скорости всегда виден. Журнал прокручивается внутри списка; открытие и закрытие записи сохраняют его положение и фокус.

Основные команды: `npm run test:e2e`; отдельная проверка установленного Chrome — `PDD_BROWSER_CHANNEL=chrome npm run test:e2e:city -- --grep 'desktop city reviews'`. Снимки находятся в `test-results/` после запуска и не хранятся в Git.

Edge, Safari, Firefox, Windows и слабые компьютеры в этой проверке не участвовали. Полная доступность со скринридером и удобство для учеников этим прогоном не подтверждены. Пилот остаётся отдельной задачей #7.
