# Левый поворот на основной зелёный

Задача #14, рабочая ветка `feat/0.3.0-preview.1`. Подготовлено 18 октября 2026 года.

Игрок должен уступить встречной машине, которая едет прямо или направо. Теперь игра запоминает подход к перекрёстку и сигнал при пересечении стоп-линии. Дальний встречный автомобиль без помехи не вызывает разбор. Если поворот заставил машину с преимуществом изменить движение, появляется карточка до столкновения.

## Откуда берётся решение

Общая функция `junctionDuty` определяет обязанность уступить для потока и проверки игрока. Она использует таблицу путей, тип перекрёстка, сигнал и сохранённый въезд. Поворотник не определяет фактический манёвр и не даёт преимущества. Для игрока направление поворота подтверждается изменением курса более 0,2 радиана после въезда; это технический порог распознавания.

Поток заранее прогнозирует пересечение с движущимся игроком на 1,5 секунды с интервалом 0,1 секунды. Прогноз нужен для торможения; сам по себе он не создаёт нарушение.

Детектор требует применимой обязанности уступить и фактической реакции связанной машины на игрока. Затем повторно рассчитывает один шаг этой машины без игрока, сохраняя сигнал, ограничение, пешеходов и остальные машины. Только дополнительное уменьшение скорости из-за игрока подтверждает помеху. Остановка в очереди или перед красным сама по себе не подходит. Это расчёт внутри домена, без изменения настоящего мира, сохранения или сетевых запросов.

Сигнал закрепляется в момент пересечения линии, с долей шага. Начатый на зелёный проезд не становится ошибкой при последующей смене фазы. Жёлтый и неизвестный сигнал не получают автоматическую оценку по этой проверке. Отдельные ситуации завершения проезда и приоритета нерегулируемых перекрёстков проходят приёмку в #15–#17; сейчас детектор игрока включён для причины `priority-left-green`.

## Разбор, история и повтор

В карточке одинаковая с картой метка машины: например, «М1». Сохраняются ID и метка, подходы обоих участников, направления движения, сигналы, прежняя и фактическая скорость другой машины и скорость расчёта без помехи. Указаны пункт 13.4, определение уступания из 1.2 и дата проверки 18.10.2026.

Без вопроса объяснение занимает всю ширину окна. Нет пустой колонки или сообщения о недостающем вопросе. Обстоятельства с метками машин показаны читаемым текстом. После перезагрузки запись читается без восстановления карты и участников. Внутренняя версия набора правил — `city-preview-1`; номер приложения пока не меняется до подготовки выпуска.

Причина отмечается один раз за проезд. После полного выезда, ухода с перекрёстка или нового подхода начинается новый эпизод. Восстановление возвращает обе машины, их маршруты, сигналы, время, случайность и состояния проверок. История остаётся; новая попытка получает другой ID. Поворот с установленной дорожной ошибкой не засчитывается как правильный только из-за включённого указателя.

## Проверки

Модульные тесты проверяют подтверждённое торможение до контакта, правильное ожидание, далёкую машину, очередь, запрещающий сигнал, совместимые пути, отсутствие правила «справа» при работающем светофоре, дубли и новый подход. Прежние проверки потока на отсутствие постоянных очередей также выполняются.

Интеграционный сценарий проходит настоящий поворот в игровой сессии, проверяет паузу, сохранение, равенство повторно полученных миров и исправление через уступание. Браузерный сценарий использует обычные клавиши, проверяет метку «М1», источник, отсутствие столкновения, повтор и чтение журнала после перезагрузки. Тестовая карта меняет только порядок допустимых маршрутов для фиксированного seed; скрытого изменения мира из браузера нет.
