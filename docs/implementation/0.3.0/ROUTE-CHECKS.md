# Проверка всей карты

Задача #4. Сценарии подготовлены 18 октября 2026 года.

Доменная проверка проходит каждый STOP и каждый светофор новой карты. Для всех 108 разрешённых соединений проверяются поворотники и отсутствие ложного нарушения встречной полосы. Для каждого типа перекрёстка проверены пары направлений, применимое преимущество, фактическая помеха, правильное ожидание и повтор. Связность, четыре квартала и безопасные позиции проверяются при загрузке и тестами дорожной сети.

Браузерные маршруты используют обычные клавиши. Они проверяют проходимость улиц, открытие и продолжение разборов, движение среди машин и видимость игрока в камере. Этот водитель намеренно допускает ошибки; отсутствие ложных нарушений на разрешённых траекториях проверяется отдельно в доменных сценариях.

| Маршрут          | Обход                                            | Результат           |
| ---------------- | ------------------------------------------------ | ------------------- |
| Северо-западный  | Центр → западная улица → северная улица → центр  | Пройдено 18.10.2026 |
| Северо-восточный | Северная улица → восточная улица → центр → север | Пройдено 18.10.2026 |
| Юго-восточный    | Центр → восточная улица → южная улица → центр    | Пройдено 18.10.2026 |
| Юго-западный     | Западная улица → центр → южная улица → запад     | Пройдено 18.10.2026 |

Проверки прежних пяти групп правил и их истории запускаются вместе с новой картой. Десятиминутная симуляция потока и три разных seed проверяют, что обычное движение продолжается без постоянных очередей и контактов машин.

Исправления, найденные по ходу проверки: двойная сплошная для широких полос; ожидание только непройденной части конфликтующего пути; исключение торможения из-за очереди и сигнала из доказательства помехи; доступный безопасный возврат из нижней панели. Детальные результаты находятся в документах соответствующих задач.

Полный запуск: 605 unit/integration тестов, сборка и 43 E2E (21 прежней карты и 22 расширенного города). Все четыре маршрута завершены клавиатурным управлением, без столкновений, с проверкой видимости машины.
