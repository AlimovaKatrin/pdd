# Проезд регулируемого перекрёстка

Задача #15, подготовлено 18 октября 2026 года. Центральный перекрёсток использует основные сигналы без дополнительных секций. Все подходы проверяются по одной модели: сигнал на стоп-линии, направление движения, обязанность уступить и фактическая помеха другому участнику.

При левом повороте водитель уступает встречному, который едет прямо или направо на основной зелёный. При включении нового зелёного — машине, которая уже завершает проезд. Смена фазы не превращает ранее разрешённый въезд в проезд на красный. Жёлтый сопровождается пояснением: возможность остановки без экстренного торможения не оценивается автоматически.

Для завершения проезда важны время въезда и начало новой зелёной фазы. Сведения о старом сигнале сохраняются, но наличие машины на перекрёстке не исчезает из-за смены фазы. Поток и проверка игрока используют одну обязанность уступить. Нарушение требует дополнительной реакции из-за игрока, подтверждённой сравнением с расчётом без него.

## Пешеход у центрального перекрёстка

На южном краю перекрёстка добавлен переход с меткой «П1» и пешеходным светофором. Его зелёный связан с разрешением движения по оси запад–восток. Пешеход начинает переход только на свой зелёный и заканчивает его после смены сигнала. Поворачивающие на эту дорогу машины уступают по пункту 13.1. Машина, начинающая движение на новый зелёный, пропускает завершающего переход пешехода по пункту 13.8.

Первое появление движения задано на 1400-м шаге симуляции. Это воспроизводимое расписание учебной сцены, а не требование ПДД. Начало перехода, намерение, реакция и эпизод входят в снимок мира. Близость неподвижной машины сама по себе не вызывает нарушение; нужна вынужденная остановка пешехода на пересекающемся пути.

Версия карты повышена до `four-blocks-2`, поскольку добавлен регулируемый переход. Старые записи сохраняют свою версию карты и объяснения. Начало, конец и связи перехода проверяются при загрузке. Прежний нерегулируемый переход у парка сохраняется.

## Проверки

Проверяются все пары направлений и границы фаз, фактическая помеха со всех четырёх подходов, законное завершение проезда, отсутствие дублей и повтор из снимка. Одновременные подтверждённые причины попадают в одну карточку с собственными ссылками на ПДД.

Пешеходные тесты проверяют разрешение начала, завершение после смены сигнала, уступание при повороте, ожидание перед переходом и отсутствие ложного события из-за близости. Интеграционный и браузерный сценарии проходят ошибку на новом зелёном, точный повтор и исправление ожиданием. История при повторе остаётся.
