# Приёмка 0.2.0-preview.1 · 09.10.2026

Исходный [план](mvp-plan.txt) реализован в технической части. **Официальный контент не принят**: пользователь выбрал КонсультантПлюс как источник ПДД, но это не заменяет проверенный комплект экзаменационных вопросов и разрешение на изображения. В игре пять явно авторских вопросов. Полный статус выпуска — предпросмотр, не готовый официальный MVP.

## Локальные проверки

- `npm run check`: типы, ESLint, Stylelint, Prettier; **70 unit/интеграционных тестов**.
- `npm run build`: production-сборка проходит. Сохраняется предупреждение Vite о большом чанке Phaser (~1.21 MB, ~332 kB gzip); оно не является ошибкой сборки.
- `npm run test:e2e`: **15 сценариев Chromium**.
- `git diff --check`: без ошибок.
- Просмотрены скриншоты старта, компактной паузы, STOP-разбора, справочника и журнала на широком/узком экране. Новые карточки и длинные материалы также проверены геометрическими E2E; это не полная визуальная экспертиза на реальных устройствах.
- Дополнительный браузерный маршрут `node scripts/check-route.mjs` пройден; положение машины проверялось по отрисованному кузову и фарам, без изменения состояния сессии. Контрольные точки (м): (67.44, 53.83), (27.84, 49.82), (23.52, 80.25), (60.06, 84.18), (66.96, 73.75). Допуск достижения точки — 4 м. Это отдельная диагностика, не часть 15 E2E.
- CI запускается после push; статус конкретного коммита проверяется в [GitHub Actions](https://github.com/AlimovaKatrin/pdd/actions). Успех прежней 0.1.0 и локальные проверки не считаются подтверждением нового запуска CI.

Основной экран: 1440×900, 1280×720, 1024×650, 800×800, 700×700. STOP-разбор дополнительно 600×700 и 390×844. Новые типы/ответы: 1280×720, 1024×650, 600×700, 390×844. Журнал: до 121 записи, включая узкий экран. Синтетический длинный материал и тестовая SVG-схема: 390×844. Масштаб браузера 100%; управление на телефоне не поддерживается.

## Производительность

Рабочая цель — компьютер с клавиатурой, актуальный Chromium, от 1024×650 CSS px. Повторный замер текущей версии: 9 октября 2026 года, 20:39 МСК. Контрольное устройство: Apple M2 Pro, macOS arm64, Node 22.23.1, headless Chromium 156.0.8078.4, Vite dev, 1280×720. Другие процессоры, Safari/Firefox и длительная игровая сессия пока не измерены.

До замера заданы диагностические бюджеты: p95 среднего времени шага в партии ≤1 мс, p95 интервала кадра ≤33.4 мс, JS heap после GC ≤128 MiB. Это локальные инженерные ориентиры, не гарантированные системные требования.

| Метрика                              | Результат                    |
| ------------------------------------ | ---------------------------- |
| 60 000 шагов                         | Среднее 0.00551 мс/шаг       |
| p95 среднего по партиям из 60 шагов  | 0.00667 мс/шаг               |
| 179 интервалов requestAnimationFrame | Медиана 16.7 мс, p95 16.7 мс |
| JS heap после GC, до/после           | 12.32 / 13.12 MiB            |

Замер симуляции не включает записи IndexedDB и реакцию UI на каждое нарушение; замер кадров — работающий город без длительного маршрута. Он подтверждает запас этой маленькой карты на контрольном устройстве, но не доказывает отсутствие утечек за часы игры. Буферы повтора ограничены 24 снимками и 20 контрольными состояниями; сама история не ограничена и выводится единым прокручиваемым списком. Журнал проверен на 121 записи; быстродействие на значительно большей истории отдельно не измерялось.

Повтор: запустить `npm run dev`, затем `node scripts/measure.mjs`. [Исходные числа и окружение](performance.json). Пилот и официальные материалы остаются отдельными незавершёнными работами.
